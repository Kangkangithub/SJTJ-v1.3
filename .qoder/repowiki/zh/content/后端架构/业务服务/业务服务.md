## 项目概述

兵智世界是一个复杂的军事武器知识管理系统，采用多数据库架构：MongoDB用于存储武器的详细文档信息，Neo4j用于构建和维护实体关系图谱，SQLite用于向量数据存储和缓存。该系统通过多个核心业务服务模块实现完整的CRUD操作、用户管理、知识图谱推理和智能问答功能。

### 技术栈特点
- **前端框架**: HTML5 + JavaScript + D3.js
- **后端框架**: Express.js
- **数据库**: MongoDB + Neo4j + SQLite3
- **AI服务**: DeepSeek LLM + 阿里云百炼Embedding
- **缓存**: Redis + 内存缓存
- **认证**: JWT + 自定义认证中间件
- **数据验证**: Joi + 自定义验证规则

| RAG响应慢 | 问答延迟过高 | LLM调用过多、并发控制不当 | 启用V2版本、调整并发参数 |
